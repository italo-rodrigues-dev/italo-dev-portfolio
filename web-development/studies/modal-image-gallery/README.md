# Image Gallery Modal

Interactive front-end study project focused on image galleries and modal interactions using JavaScript.

## Features

- Clickable image gallery
- Modal image preview
- Keyboard interaction (Escape key)
- Click outside to close modal
- Dynamic image rendering
- Overlay interface

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- DOM manipulation
- Event listeners
- Modal interfaces
- Keyboard events
- Dynamic attribute manipulation
- Responsive overlay design
