# Student Grade System

Interactive web application developed during an in-person practical web development exam without internet access.

The objective was to recreate a complete interface and its functionalities based only on a visual demonstration provided by the instructor.

## Features

- Student registration
- Grade calculation
- Approval/rejection system
- Dynamic table rendering
- Class average calculation
- Dynamic row coloring
- Form validation

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- DOM manipulation
- Dynamic table generation
- Conditional rendering
- Event listeners
- Form validation
- State management
- Functional decomposition

## Context

This project was developed under time constraints during a supervised practical exam environment without access to external resources or internet research.
