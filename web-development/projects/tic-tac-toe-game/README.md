# Tic Tac Toe Game

Interactive Tic Tac Toe web game developed with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Dynamic board updates
- Victory detection
- Draw detection
- Score tracking
- Game restart system
- Interactive UI

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- DOM manipulation
- Arrays and state management
- Event listeners
- Conditional logic
- Dynamic rendering
- Game logic implementation
